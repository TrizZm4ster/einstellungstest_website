Alle Einstellungstests stellen eine realistische Simulation dessen dar, was Schülerinnen und Schüler auch in einem echten Auswahlverfahren für einen Ausbildungsplatz erwarten könnte. 
Der Umfang ist so ausgelegt, dass innerhalb einer 67-minütigen Unterrichtsstunde zwei Tests bearbeitet werden können. Zielgruppe sind Schülerinnen und Schüler die nach der 10. Klasse eine Ausbildung beginnen wollen.
Die Tests sind nach gängigen Ausbildungsgängen in fünf Kategorien gruppiert

All recruitment tests realistically simulate what students might encounter in an actual selection process for a vocational education and training (VET) place. 
The scope is designed so that two tests can be completed within a single 67-minute class period. The target group is students who plan to begin a VET programme after Grade/Year 10. 
The tests are grouped into five categories based on common VET occupations.


Alle Fragen in allen Tests wurden überprüft, damit die Tests Einstellungstests möglichst realistisch nachbilden. 
Um automatisiertes Feedback einzubauen entfallen Freitextaufgaben wie Aufsätze, die in echten Tests häufig vorkommen.

All questions in all tests have been reviewed to ensure that the tests closely simulate real recruitment tests. 
To enable automated feedback free-text tasks such as essays, which are common in real tests, were omitted.
