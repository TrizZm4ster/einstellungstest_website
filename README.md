# Einstellungstests

## Deutsch

**Unterrichtsmaterial**
Abrufbar unter: [https://trizzm4ster.github.io/einstellungstest_website/](https://trizzm4ster.github.io/einstellungstest_website/)

Alle Einstellungstests stellen eine möglicht realistische Simulation dessen dar, was Schülerinnen und Schüler auch in einem echten Auswahlverfahren für einen Ausbildungsplatz erwarten könnte. Der Umfang ist so ausgelegt, dass innerhalb einer 67-minütigen Unterrichtsstunde zwei Tests bearbeitet werden können. Zielgruppe sind Schülerinnen und Schüler, die nach der 10. Klasse eine Ausbildung beginnen wollen. Die Tests sind nach gängigen Ausbildungsgängen gruppiert.

Alle Fragen in allen Tests sind Ki generiert; wurden jedoch händisch überprüft. Um automatisiertes Feedback einzubauen, entfallen Freitextaufgaben wie Aufsätze, die in echten Tests häufig vorkommen.

> **Hinweis:** Der JS/CSS/HTML-Code ist ausschließlich KI-Slop (Claude Sonnet 5.5).

## English

**Teaching material**
Available at: [https://trizzm4ster.github.io/einstellungstest_website/](https://trizzm4ster.github.io/einstellungstest_website/)

All recruitment tests realistically simulate what students might encounter in an actual selection process for a vocational education and training (VET) place. The scope is designed so that two tests can be completed within a single 67-minute class period. The target group is students who plan to begin a VET programme after Year 10. The tests are grouped based on common VET occupations.

All questions in all tests are generated by AI; but have been reviewed manually. To enable automated feedback, free-text tasks such as essays, which are common in real tests, were omitted.

> **Note:** The JS/CSS/HTML is entirely AI slop (Claude Sonnet 5.5).
